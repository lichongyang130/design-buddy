# 栖野 QIYE · 周末旅行 App 案例

## 打开

- `/qiye-app.html`：独立交互原型，不依赖账号或外部 API。
- 模板页 `/templates.html` → 形式「App」→「栖野 · 周末旅行 App」。缩略图为独立设计的品牌封面（真实手机首页截图＋原有旅行场景背景），点击打开可操作的完整案例，不再使用被裁切的只读 iframe。
- `npm run build` 后，直接预览首页：`PORT=5176 PREVIEW_ENTRY=qiye-app.html node server.mjs`。服务器默认行为保持工作区首页不变。

## 六个页面

1. `#home`：移动端首页、紧凑搜索入口、主视觉卡片、四种快捷分类、横滑推荐。
2. `#discover`：即时搜索、主题与天数组合筛选、清空与无结果状态。
3. `#destination/mountain` 等：五个目的地、图片切换、收藏、加入行程。
4. `#trips`：新建 1–3 天行程、多个行程切换、添加/移除目的地、同日上移/下移、日期调整、删除确认、示例预算合计。
5. `#saved`：收藏列表与取消收藏、空状态。
6. `#profile`：昵称、偏好、紧凑布局、本地数据清空确认。

路线支持直接打开及浏览器前进后退；桌面也只展示固定宽度的手机预览，不再扩展成侧栏网站；手机端为全屏界面。内容区独立滚动，一级页面固定底部五个 Tab，详情页切换为底部固定操作栏。不同 Tab 保留各自浏览位置。创建行程、选择行程、编辑和确认操作均使用屏幕内的底部抽屉，支持 Escape、焦点圈定及关闭后焦点返回。图标有语义标签，交互状态使用 aria-pressed / aria-current，反馈使用 aria-live。

## 数据与范围

本地键：`design-buddy-qiye-v1`。收藏、行程、昵称、偏好和紧凑布局刷新后保留。损坏数据、安全存储不可用、未知目的地、重复地点均有保护。昵称与行程名称转义后输出。

所有目的地、预算、车程均为演示内容；不核实实际交通距离，不执行支付、预订、导航或实时天气请求。预算合计仅汇总示例金额，不能作为费用承诺。没有声称具备原生安装包、账号同步或生产后端。

五张专属 AI 场景图位于 `public/art/qiye`，分别为山野、海岸、古镇、林居、湖泊。`manifest.json` 记录摘要与 SHA-256。图片不是纪实摄影；详情切换图为不同场景灵感，不冒充同一真实地点。

自托管字体来自 Fontsource 的 Noto Sans SC / Noto Serif SC 400 字重，为界面实际使用字符选择的分片。许可证与版权信息保留在 `public/art/qiye/fonts`。运行时不依赖 Google Fonts 或外部字体服务，未涵盖的自定义昵称字符回退系统字体。

## 验证

在 5174 上运行静态预览后：

```sh
npm run build
node tests/verify-qiye-app.mjs
node tests/verify-template-engine.mjs
node tests/verify-regression.mjs
```

附加 Chromium 实测：六个页面 × 360、390、768、1440 四档宽度无横向溢出；无页面错误、无失败资源请求；手机创建行程、即时搜索和刷新后持久化通过。浏览器与截图属于本地验证工具/临时产物，不加入项目依赖或版本库。

## App 视觉重构

已移除网站侧栏、宽屏三列布局、网页页脚和居中的网页弹窗。桌面手机容器宽 414px（包含设备边框），内容、状态栏、底部导航和 Home Indicator 组成独立视口。手机端去除边框并铺满屏幕。顶部 9:41、信号和电量是不可操作的原型示意，不代表读取了真实系统状态。

首页推荐支持横向滑动；发现页为双列目的地卡片；收藏页为横向信息列表；详情页底部「加入我的行程」始终可见；行程为单列日程时间线；资料页为个人卡片和设置列表。演示仍运行于浏览器，并非原生安装包。

重构后附加 Chromium 验证：360×740、390×844、768×900、1440×1000 下六个页面均无整页横向/纵向滚动溢出，滚动仅在 App 内容区；桌面容器不超过 414px。首页 Tab 的滚动位置保留、底部 Tab 与详情操作栏固定、底部抽屉不超出设备边界、手机创建行程及刷新后恢复均已实测。

## 作品展缩略图

`public/art/qiye/cover.webp` 为 1200×714 的独立作品封面：左侧栖野品牌标题，右侧真实手机界面及淡化旅行背景。不是 AI 生成的虚构 UI。App 页面本身不变。

`scripts/make-qiye-cover.mjs` 可从运行中的预览重新抓取首页并排版、导出 WebP。需要可用的本地 Playwright / Chromium；可用 `QIYE_PLAYWRIGHT_MODULE` 和 `QIYE_CHROMIUM_MODULE` 指向外部工具安装，或通过 `QIYE_BROWSER_EXECUTABLE` 指定 Chromium。`QIYE_PREVIEW_URL` 默认 `http://127.0.0.1:5174`，仅用于构建时截图，不会出现在浏览器运行代码的 API 地址中。

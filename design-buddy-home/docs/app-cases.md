# 50 个移动 App 浏览器原型

入口：`/apps.html`，或模板库中的 **App** 筛选。原六页栖野仍在 `/qiye-app.html`，不重复计入新目录；目录中的栖野是 20 页扩展原型。

## 实际范围

- 50 个案例；旅行、饮食、运动、阅读、植物、宠物、文化、效率、学习、居家各 5 个。
- 每个 20–24 个已注册的功能页面，共 1,100 个案例页面路由。页面目录右上角可直接打开全部页面。
- 24 种功能页面视图共享实现，不代表 1,100 份手写界面或 50 套原生代码库。各例采用不同首页模块排列（50 种实际 DOM 顺序）、10 种视觉家族，以及 5 种专题构图、卡片结构、底部导航、3 种页头。不是只换名字与颜色；框架组合见 `src/app-catalog.js` 和素材 manifest。
- 移动布局：固定主导航/详情操作栏，独立内容滚动，设备内底部弹层。500px 以下全屏，不使用桌面网站侧栏；桌面中保留手机比例。
- 浏览器交互原型，无原生安装包、后端账号、支付、预订、导航、远程通信或真实教学服务。

## 页面与操作

所有案例：

首页、发现、分类、详情、图集、收藏、内容夹列表/详情、计划列表/详情、新建计划、行动清单、动态、笔记列表/编辑、消息列表/详情、搜索、我的、偏好设置。

按案例页数增加：完成进度、真实倒计时、使用指引、体验反馈。

可操作：

- 实时搜索、分类筛选与重置，收藏/取消收藏；
- 创建内容夹、添加/移除内容、删除内容夹；
- 创建计划、修改名称/日期、添加/移除/上下排序内容，逐项勾选内容对应准备步骤；
- 创建、关联、编辑和删除笔记；用户文本安全转义；
- 消息已读与本地回复，明确不会对外发送；
- 编辑昵称，紧凑布局与减少动效开关，清空当前案例数据；
- 内容完成标记；可用案例的进度来自实际本地状态，评分为本地反馈；
- 可用案例的 5/15/25 分钟计时可启动、暂停、重置，刷新后按截止时间恢复。

状态键：`design-buddy-appcase-v1:<case-id>`。50 个案例隔离。损坏数据会回退并过滤无效条目；无 localStorage 时继续临时使用并提示无法保存。清空一个案例不影响其他案例。没有云端备份。

## 图像与缩略图：不要混淆来源

- `public/art/apps/*.webp`：**10 张 AI 领域主题场景**，每张由同领域的 5 个案例共享；不是 50 张各例专属 AI 图片，也不是纪实照片。
- `src/app-case-art.js`：10 领域的参数化内容 SVG 组合，每例 5 个带标题内容组合。图形母题按领域共享，不能将 250 个带标题组合描述成 250 张独立 AI 创作。SVG 为内联形式，可使用自托管中文字体；每一个功能页都有内容图形或主题图片，包括空状态。
- `public/art/apps/covers/*.webp`：**50 张独立品牌封面**，每张用对应真实首页截图排版，而不是 iframe 或虚构 AI 界面。1200 × 714；构图、字重、背景、手机摆放随案例组合变化。
- `public/art/apps/manifest.json`：完整案例、页面、结构配方、图片来源、共享关系、文件体积和 SHA-256。
- `public/art/apps/fonts/`：补充 Noto Sans SC 400 分片及 OFL 授权；原栖野已包含的分片复用原路径，未重复复制。
- 不改变历史 712 个演示/文档案例的配图完成数量。

## 维护与验证

```
npm run build
node tests/verify-app-cases.mjs
node tests/verify-qiye-app.mjs
node tests/verify-template-engine.mjs
node tests/verify-regression.mjs
```

真实浏览器测试和封面脚本使用可选的外部 Playwright/Chromium 环境，不为生产应用新增依赖：

```
APP_PLAYWRIGHT_MODULE=/absolute/path/playwright-core/index.mjs \
APP_CHROMIUM_MODULE=/absolute/path/@sparticuz/chromium/build/index.js \
node tests/verify-app-cases-browser.mjs

# 同样环境变量；默认已运行的构建服务 http://127.0.0.1:5174
node scripts/make-app-case-covers.mjs
node scripts/make-app-case-manifest.mjs
npm run build
```

`APP_PREVIEW_URL` 可指定本机测试服务 URL；仅供 Node 脚本使用，浏览器代码始终使用同源相对路径。

真实浏览器测试：遍历全部 1,100 页面，检查渲染/内容插图/无横向溢出；逐例测试核心写入、排序、编辑、搜索、筛选、消息和刷新保存；测试计时、评分、删除；10 家族 × 4 屏幕尺寸检查；验证目录筛选和搜索、无 JS/HTTP 错误。模型测试中的 50 个封面 SHA/250 个 SVG 字符串唯一检查仅验证文件/内容标识，不等于视觉质量或 250 种不同图形母题。

专用预览可用：`PORT=5177 PREVIEW_ENTRY=apps.html node server.mjs`。原站入口与初版栖野不受影响。

# 首页独立问答界面

仅普通、未选择创作类型的问答进入新界面。选中演示文稿/文档/图片/轮播图/美化/导入，或使用技能/专家时，继续原有生成流程。未选类型但明确要求制作 PPT、文档等产物，也保留原流程；「如何制作演示文稿」等询问方法的问题属于问答。

界面按提供截图实现：浅蓝底、右侧用户气泡、可选模板引用卡、左侧蓝色思考状态、底部固定宽输入框、添加附件/语音/停止按钮。无模板引用时不伪造 Petalpush 卡片。当前首页已有的示例引用入口不在本次修改范围内。

- 停止、重试、追问；Enter 发送，Shift+Enter 换行，兼容输入法；生成状态变化保留输入草稿。
- 对话写入原有 conversations，使用 `kind: question`，不创建 Gamma、创作任务或扣减积分。
- 最近的对话记录可重新打开；刷新恢复对话，未完成状态显示已中断。
- 返回首页后恢复原工作区。手机使用全宽布局，输入框固定底部，消息区域独立滚动。
- 语音使用浏览器 SpeechRecognition，权限失败或不支持时提示。新聊天输入框的附件目前仅记录文件名，并明确标注；首页已读取的附件上下文随首条消息本地保存。
- 普通问答通过同源 `/api/models/chat` 调用当前所选 OpenAI 兼容模型；需要服务器环境密钥或设置页测试成功后建立的 30 分钟临时凭据会话。没有密钥或网络失败时显示真实错误，不伪造回答。
- 当前采用完整 JSON 响应而非流式输出；停止/离开会取消请求，迟到响应不能覆盖已停止状态。重试不将旧回答当成新提示。模型输出以纯文本转义显示。测试/问答可能产生供应商费用，不扣应用本地积分。附件和上下文尚未发送给模型，仅发送用户/助手文字消息。
- 产物生成器仍走原有路径，本轮只接通普通问答。当前沙箱没有真实密钥且模型域名出站受限，官方 API 未实测。配置方法见 `docs/model-setup.md`。

文件：`src/question-routing.js`、`src/question-chat.js/css`；`src/main.js` 仅增加分流、历史打开和恢复入口。未替换演示文稿、文档等生成器。

验证：`npm run build`、`node tests/verify-question-chat.mjs`、`node tests/verify-home-presentation.mjs`。真实 Chromium 已检查桌面截图、停止/追问、刷新恢复、手机无横向溢出和返回首页。

补充回归：图片工作台 64 项、导入 46 项、美化 43 项均通过。完整持久化测试仍有 4 项模板相关断言未通过；本次未调整模板逻辑，也未将其标为通过。

# 技能定位与精简（2026-10-30）

## 源码主要做什么

Design Buddy 是围绕 **演示文稿、文档、轮播内容、图片与网页原型** 的设计和内容创作工作台，不是通用 RPA、财经查询或无人值守办公平台。

- `src/main.js`：创作入口、工作区、文件引用、技能调用及结果展示。
- `src/model-manager.js`、`server/api-models.mjs`：模型配置与服务端模型请求；实际 AI 能力取决于已配置的可用模型服务。
- `src/document-generator.js` 与模板相关模块：文档创作与交付链路。
- `public/atelier/`：现有案例、原配图、在线查看器与可下载原文件。
- `src/skills-catalog.js`、`skill-runtime.js`：技能发现、安装、规则引擎和可下载结果。这里的本地规则技能不等同于大模型、联网搜索或系统自动化。

## 当前推荐的 18 项

| 用途 | 技能（界面显示名称） |
| --- | --- |
| 演示与表达 | PPT 大纲生成、文案润色、数据图表化、长文摘要、SEO 关键词规划 |
| 文档处理 | CSV / TSV 表格分析、文本分页与目录、Markdown 转 Word（.doc）、HTML 转 Markdown |
| 设计与原型 | 页面布局、品牌色与设计令牌、原型搭建、HTML 响应式规则检查 |
| 审查与交付 | 交付文本与源码自检、方案假设与风险审查、文档结构检查、页面可访问性检查、素材引用清单 |

说明按当前实现重写：不把 HTML `.doc` 叫原生 DOCX，不把文本分页叫 PDF 解析，不把 CSV 统计叫 Excel 文件编辑，不把源码规则检查叫截图视觉比对。取消虚构的调用量、下载量展示。

## 不再推荐的内容

- 重复专家转发项：如大纲规划/故事线设计等多项实际调用同一专家引擎，不再为同一实现堆叠技能入口。
- 超出当前能力的名称：背景移除、定时任务、文件夹监听、自动交付、深度联网调研、自动化工作流执行等。
- 弱相关或实现不足：邮件助手、仅术语替换的“中英互译”、并非通用 SQL/Parquet 引擎的“数据即查”。

旧源码、运行别名和已安装记录 **不物理删除**，避免用户数据丢失或旧调用失效。旧能力在已安装页明确标记；新的推荐和默认安装不再推广这些项。全新用户的默认四项为大纲、润色、图表、文档结构检查；旧用户的数组不会被新默认值覆盖。自定义技能记录不受此次精简影响。

## 新增的三个实际引擎

1. **文档结构检查**：识别 Markdown / HTML 标题，检查层级跳跃、重复和空标题、待填项、长段落；输出目录、JSON 与 Markdown 报告。不是 Word/PDF 真实页数检查。
2. **页面可访问性检查**：在惰性模板中解析 HTML，检查图片 alt、控件标签、按钮和链接名称、标题层级、重复 id。不会执行用户脚本或加载其图片，不作 WCAG 认证，不替代键盘、读屏和对比度实测。
3. **素材引用清单**：提取 HTML / Markdown 中的资源引用，按类型和原始路径去重，输出引用清单和警告。不下载资源，不检查版权、实际文件存在性或外链可达性；内联资源仅标记存在。

新增技能均接入发现、精选、安装持久化、技能运行面板和原有 `runSkill` 调用通道。存储/执行的 canonical name 与界面显示名分离，旧 ID 和旧调用名称不改。

## 验证

- `npm run build`：含四语言字典与模板原件完整性检查。
- `npm run test:creation-skills`：18 项均有实际产物；新引擎规则、去重、错误输入、JSON 真下载、旧安装保留、无脚本执行/外链加载，以及信任/高风险确认策略。
- `node tests/verify-settings-real.mjs`：105 项，包含精简后的可安装项、旧版安装兼容、自动更新和语言设置。高风险技能已从发现中退出，其确认策略仍保留并由新测试覆盖。
- `npm run test:ui-language`：四语言与八页面回归。
